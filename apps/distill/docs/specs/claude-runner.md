# Claude runner

The Claude Code implementation of [AI runners](ai-runners.md). Every unit of
work is one or more non-interactive `claude -p` turns in a single Claude Code
session. Code: `clients/macos/Sources/WorkerCore/Runners/ClaudeCodeRunner.swift`,
`clients/macos/Sources/WorkerCore/WorkerEngine.swift` (`runTurn`).

## Invocation

- Working directory: the vault root. Sessions are keyed by cwd, so every turn of
  a job, including resumes, runs from the same vault.
- Arguments (`ClaudeInvocation.arguments`):
  `-p --output-format json --model <id>`, `--effort <level>` when set, then `--session-id <uuid>` on the first
  turn or `--resume <uuid>` afterwards, `--plugin-dir <productRoot>`,
  `--add-dir <productRoot>`, `--json-schema <WorkerProtocol.schema>`,
  `--append-system-prompt <WorkerProtocol.systemPrompt>`, and
  `--allowedTools` followed by one argv entry per rule (a comma inside a rule
  must not split it).
- The prompt is written to stdin, never passed as an argument.
- Environment: `CLAUDE_OBSIDIAN_VAULT=<vault>` and an explicit `PATH` (GUI apps
  inherit a minimal one).
- The session id is generated by the app (`--session-id`) so it is known before
  the first turn completes. `--resume` keeps the same id (verified).

## Output

`--output-format json` returns an envelope. `ClaudeResult.parse` reads
`session_id`, `result`, `is_error`, `total_cost_usd`, `structured_output`, and
`permission_denials` (`tool_name`, `tool_input`). The raw envelope of each turn is
saved as `<vault>/.vault-meta/worker/<job-id>/turn-<n>.json`.

## Structured status

`--json-schema` forces every turn to end with
`{status, summary, bundle_path?, questions?, operation_id?, changed_paths?, skipped?}`
where `status` is one of `needs_approval`, `needs_input`, `done`,
`nothing_to_do`, `failed` (`WorkerStatus`). A missing structured output is
treated as `needs_input` with the plain result text.

## Process handling

`ProcessRunner` drains stdout and stderr concurrently (no pipe deadlock) and
supports cancel (terminates the process; the job becomes `cancelled` and can be
resumed by replying).
