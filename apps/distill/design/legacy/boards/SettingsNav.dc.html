Used to write a new message from a note
Write a short Slack message to {recipient} that does what the note asks.
Use only facts from {excerpt} and {note_title}. Don’t invent times, names or numbers.
Friendly and direct, under 80 words. Use Slack formatting: *bold*, bullet lists, @mentions.
Return only the message.

Used after you edit a message. Different from the create prompt.
The user edited this Slack message. Fix grammar, spelling and punctuation only.
Keep their words, tone, length and formatting. Don’t add or remove content.
Return only the message.
