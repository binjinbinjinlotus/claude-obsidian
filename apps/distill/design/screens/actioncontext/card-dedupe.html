RE-READS AND REPAIR DON’T REPEATA repair reads the same content from .raw/captured/<sha>.md instead of inbox/…. Actions are matched by the original’s content hash, not its path:
Same content hash, same type and overlapping lines → the same action, whatever its status (done, removed, sent, dismissed).
Same content hash and the same quote → the same action.
Older items without lines: their quote is looked up in the new original, so they count too.
Within one pass only the title rule applies: one sentence can hold a to-do and a message.
Review then says “1 was already in Actions and isn’t shown again”.
