↑↓Move between To confirm rows; the pane follows
↩Add / Create draft for the selected row, then select the next
⌫Dismiss the selected row, then select the next
⌘↩Add while a text field has focus
The keys work while the list has focus (click a row, or Tab into it). Return never fires inside the title editor, Add to-do or search. After the last row the selection moves to the open to-dos.
