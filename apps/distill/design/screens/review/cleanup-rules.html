A file can go only when all three hold1. The source ledger (wiki/meta/ledgers/source-ledger.json) has an entry whose origin.locator is this file’s path in the vault.2. The file’s sha256 now equals that entry’s content_sha256: unchanged since it was added.3. Every page in that entry’s pages exists.Names are compared in Unicode NFC. When no locator matches exactly, a case-only difference counts, and only when one entry matches and its hash agrees. A note’s .distill.json and the images it lists go with it. A folder from a batch goes as one: only when every source file inside passes (a “seen before” file needs its own entry), with its .distill-folder.json.Never: a file a batch waiting in Review or running has taken, or a queued file not yet batched (the queue may be inbox/ itself). Checked again when you press Move: a file that changed in between stays. Moved to the macOS Trash, never deleted. Distill never cleans up on its own.
