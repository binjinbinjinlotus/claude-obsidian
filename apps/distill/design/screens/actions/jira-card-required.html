FROM JIRA’S CREATE SCREENThe fields come from Jira’s create screen for each project and type, with their names and types, refreshed with the pickers (cached an hour per account).
NAMES, NEVER IDSA field shows its display name from Jira (“Team”), never customfield_11063. A long name wraps inside the label column.
THE CONTROL FOLLOWS THE TYPEOne choice → a picker of Jira’s allowed values · several → chips · text → a field, long text → an area · number · date → a date picker · person → a people search · cascading → parent, then child. An unknown type: Distill can’t fill it; Open in Jira.
ONLY WHAT’S NEEDEDRequired fields always show, marked “Required by TLS”; Create waits until they’re filled. Optional fields aren’t shown unless a default is set. A value the note names exactly (ignoring case) is prefilled with “from the note”.
