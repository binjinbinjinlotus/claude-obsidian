# PrimaryButton

The one blue action in a window. Same name and props as `PrimaryButton` in `Theme.swift`: `title`, `systemImage` (an SF Symbol name the bundle knows: `checkmark`, `plus`, `paperplane`, `clock`, `exclamationmark.circle`), `size` (`regular` 40, `small` 30, `mini` 26) and `enabled` (off: 45% opacity). Only the regular size casts the blue shadow. Use one per window; secondary actions are SoftButton.
